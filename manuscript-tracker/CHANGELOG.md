# Changelog

## 1.1.0 – 2026-10-30

### Added
- Optional sync across devices through a private repository in the user's own GitHub account. It uses a fine-grained token limited to that repository.
- Deletions sync across devices.
- Content Security Policy that only allows connections to `api.github.com`.
- `tests/sync-test.html`: merge and sync tests against a mock GitHub API.
- Chinese README (`README.zh-CN.md`).

## 1.0.0 – 2026-10-30

### Added
- Parse editorial emails from IEEE ScholarOne, Elsevier Editorial Manager and Springer Nature.
- Per-manuscript timelines, status filters, revision countdowns, JSON/CSV export and import.
- English and Chinese interface.
